## Abstract
Weight-Space Programming (WSP) is a nascent paradigm in which a general-purpose LLM reads, writes, or edits the raw parameters of a neural network directly, guided only by a natural-language specification and without gradient-based optimization. This scoping review synthesizes fifteen primary studies and the founding essay, organizing them around reading, writing, and editing weights, and distills cross-cutting limitations and a research agenda.
